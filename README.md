# World Brief

Automatic daily news carousels and Reels for Instagram **@worldbrief_official**.

- `engine/render.js` is the locked post design (1080×1350 slides).
- `engine/make-reel.sh` turns slides into a 9:16 Reel with music.
- `scripts/ig.js` handles Instagram API posting, comments and insights (token from the `IG_TOKEN` environment variable only).
- `RUNBOOK.md` is what the scheduled Claude Code cloud routines follow.
- `LEARNINGS.md` holds the rules learned from performance reviews.
- `media/` holds the published slides and Reels (public links that Instagram downloads).
